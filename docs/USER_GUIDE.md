# 📘 คู่มือการใช้งาน DemoApp Dashboard

## 1. เปิดใช้งาน

| วิธี | ขั้นตอน |
|---|---|
| **ผ่าน GitHub Pages** | เปิด `https://<org>.github.io/<repo>/` — เป็นเวอร์ชันที่อัปเดตอัตโนมัติทุกวัน 07:00 น. |
| **เปิดจากไฟล์** | ดับเบิลคลิก `index.html` ได้เลย (ต้องต่ออินเทอร์เน็ตเพื่อโหลด Chart.js / DataTables จาก CDN) |
| **รันเป็นเว็บเซิร์ฟเวอร์** | `python -m http.server 8080` แล้วเปิด <http://localhost:8080/index.html> |

> เบราว์เซอร์ที่รองรับ: Edge / Chrome / Firefox / Safari เวอร์ชันปัจจุบัน ทั้งบน Desktop และ Mobile

## 3. การค้นหาและกรองข้อมูล

1. **Search Box** — พิมพ์คำใดก็ได้ ระบบค้นทุกคอลัมน์พร้อมกัน (ชื่อลูกค้า, รหัสลูกค้า, เลขทะเบียน, จังหวัด, ผู้ยื่น, ชื่อผู้ติดต่อ ฯลฯ) มี debounce 250 มิลลิวินาที จึงลื่นแม้ข้อมูลเยอะ
2. **Filter ตาม Status** — เลือกสถานะเดียว เช่น `รอการพิจารณาเบื้องต้น`
3. **Filter ตาม Category** — เลือกประเภทคำขอ / ทีม / จังหวัด
4. **Filter ตามวันที่** — กำหนด "วันที่เริ่ม" และ/หรือ "วันที่สิ้นสุด"
5. **Sort** — เลือกคอลัมน์ที่ต้องการเรียง แล้วเลือกทิศทาง Ascending / Descending (หรือคลิกหัวตารางก็ได้)
6. กด **ล้างตัวกรอง** เพื่อกลับสู่ค่าเริ่มต้น

> ตัวกรองทั้งหมดเป็น **ตัวกรองกลาง** — มีผลกับ KPI, กราฟทุกตัว, ตาราง และไฟล์ที่ Export พร้อมกัน

**Drill Down**
- คลิก **แถวใดก็ได้ในตาราง** → เปิด Panel ด้านขวาแสดงทุกฟิลด์ของรายการนั้น พร้อมปุ่มเปิดรายการจริงใน SharePoint
- คลิก **แท่งในกราฟสถานะ** หรือ **ชิ้นในกราฟประเภทคำขอ** → ระบบตั้งตัวกรองให้อัตโนมัติแล้วพาไปหน้า "ค้นหา / ตาราง"
- ปิด Panel ด้วยปุ่ม ✕ คลิกพื้นที่มืด หรือกด `Esc`

## 6. การแก้ปัญหาที่พบบ่อย

| อาการ | สาเหตุ / วิธีแก้ |
|---|---|
| กราฟไม่ขึ้น / ตารางเป็นข้อความเปล่า | เครื่องเข้า CDN ไม่ได้ — ให้ดาวน์โหลดไลบรารีมาไว้ในโฟลเดอร์ `vendor/` แล้วแก้ `<script src>` ในไฟล์ให้ชี้ path ในเครื่อง |
| Workflow ล้มที่ขั้นตอน Build | ตรวจว่าใส่ Secrets ครบ 3 ตัว และ Azure AD ให้สิทธิ์ `Sites.Read.All` แบบ **Application** พร้อม Grant admin consent แล้ว |
| ข้อมูลไม่อัปเดต | ดูแท็บ Actions ว่างานรันผ่านหรือไม่ • ถ้าไม่มีข้อมูลเปลี่ยน workflow จะข้ามการ commit โดยตั้งใจ |
| ภาษาไทยเพี้ยนใน CSV | เปิดด้วย Excel เวอร์ชันปัจจุบัน — ไฟล์ใส่ BOM ไว้แล้ว หากยังเพี้ยนให้ใช้ Data → From Text/CSV และเลือก encoding UTF-8 |
| ข้อมูลเยอะแล้วช้า | ตารางเปิด `deferRender` อยู่แล้ว หากเกินหลักแสนแถว แนะนำให้ `build_dashboard.py` เขียนข้อมูลเป็น `data/demoapp.json` แยก แล้วให้หน้าเว็บ `fetch()` แทนการฝังในไฟล์ |
