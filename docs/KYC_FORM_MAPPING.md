## 3. วิธีใช้งาน

1. เปิด `print.html` (หรือกดปุ่ม **🖨️ พิมพ์เอกสาร KYC** จาก Dashboard)
2. **เลือกรายการ** — พิมพ์ชื่อบริษัท / รหัสสมาชิก / เลขทะเบียน ในช่องค้นหาด้านบน แล้วเลือกจากรายการที่ขึ้นมา
   *(หรือเข้าจากหน้ารายละเอียดใน Dashboard → ปุ่ม 🖨️ จะเปิดรายการนั้นให้เลย)*
3. กด **"แก้ไขก่อนพิมพ์"** เพื่อเติมช่องที่ยังว่าง (ช่องจะกลายเป็นแก้ไขได้ พร้อมพื้นหลังเหลืองอ่อน)
4. กด **"พิมพ์ / บันทึก PDF"** → เลือกเครื่องพิมพ์ หรือ **"Save as PDF"**
   - ชื่อไฟล์ตั้งอัตโนมัติเป็น `KYC-{รหัสสมาชิก}-{ชื่อบริษัท}`
   - แถบเครื่องมือทั้งหมดจะไม่ถูกพิมพ์ (`@media print { .toolbar { display:none } }`)

### ตั้งค่าเครื่องพิมพ์ที่แนะนำ
| ค่า | ตั้งเป็น |
|---|---|
| Paper size | A4 |
| Layout | Portrait |
| Margins | Default (เทมเพลตกำหนด 8 มม. ไว้แล้ว) |
| Scale | 100% |
| Background graphics | ✅ เปิด (เพื่อให้หัวข้อมีพื้นหลังเทา) |

## 4. รายละเอียดเชิงเทคนิค

- **CSS Grid 12 คอลัมน์** — ทุกแถวใช้คลาส `.c1`–`.c12` และรวมกันได้ 12 พอดี (ตรวจด้วยสคริปต์แล้ว **16/16 บล็อกผ่าน**)
- **กฎการพิมพ์**
  ```css
  @page { size: A4 portrait; margin: 8mm }
  .sheet { width: 194mm; min-height: 281mm; page-break-after: always }
  ```
- **เส้นประอัตโนมัติ** — `.vl:empty::after { content:''; border-bottom:1px dashed #b9bec7 }`
  ช่องที่ไม่มีข้อมูลจะกลายเป็นเส้นให้เขียนมือทันที
- **`normKey()`** — ถอดรหัสชื่อคอลัมน์แบบ SharePoint (`Customer_x0020_Name` → `customername`)
  ทำให้หน้าพิมพ์อ่านข้อมูลได้ทั้งจาก CSV และจาก Microsoft Graph API
- **ตารางโครงการ** สร้างด้วย `projectRows(id, spans, count)`
  - อดีต `[3,2,2,2,1,2]` × 3 แถว · ปัจจุบัน `[3,2,2,2,3]` × 3 แถว · อนาคต `[3,2,2,2,3]` × 2 แถว
- **คลาสเซลล์พิเศษ**
  | คลาส | ใช้ทำอะไร |
  |---|---|
  | `.cell.dense` | เซลล์เตี้ยพิเศษ (`min-height:7mm`) สำหรับตารางโครงการ |
  | `.cell.memo` | กล่องบันทึกสูง 34 มม. มีเส้นบรรทัดเขียนมือ 5 บรรทัด (`repeating-linear-gradient`) ใช้กับประวัติผู้บริหาร/กิจการ |
  | `.head .slogan` | สโลแกน "ครบ ถูก ดี" มุมซ้ายบนหน้า 2 |
  | `.chk` | ช่องติ๊ก ☑ หน้าชื่อโครงการ |
- **โหมดบีบอัดหน้า 1** — หน้า 1 มี 33 แถว / 8 แถบหัวข้อ จึงใช้ CSS เฉพาะ `#page1` ลดความสูงเซลล์เหลือ `min-height:5.6mm` และย่อฟอนต์ label/value
  ```css
  #page1 .cell      { min-height:5.6mm; padding:.3mm 1.2mm }
  #page1 .cell .lb  { font-size:8px;    line-height:1.05 }
  #page1 .cell .vl  { font-size:10.5px; min-height:3.4mm }
  #page1 .cell.dense{ min-height:4.6mm }
  #page1 .band      { margin-top:1mm; padding:.4mm 2mm; font-size:11px }
  ```
- **`fullAddr()`** — ประกอบที่อยู่เต็มหน้า 2 จาก 5 คอลัมน์ (ขึ้นต้นด้วย `project_location1`) เติมคำนำหน้า `ต.` / `อ.` / `จ.` อัตโนมัติ พร้อม regex กันคำนำหน้าซ้ำ
- **`thDay()`** — แปลงค่าคอลัมน์ `Data` เป็นวันที่ไทยแบบไม่มีเวลา สำหรับช่อง "วันจดทะเบียน"
  | ค่าที่รับเข้า | ผลลัพธ์ |
  |---|---|
  | `02/25/2015 17:00:00` (MM/DD/YYYY) | `25/02/2015` |
  | `01/27/2008 17:00:00` | `27/01/2008` |
  | `25/02/2015` (ตัวแรก > 12 → เดาเป็น DD/MM/YYYY) | `25/02/2015` |
  | `2015-02-25T10:00:00Z` (ISO 8601) | `25/02/2015` |
  | `3/7/2020` | `07/03/2020` |
  | ค่าว่าง / `null` | *(ว่าง → ขึ้นเส้นประ)* |

  > เหตุผลที่ไม่ใช้ `new Date()` ตรง ๆ — ค่าในลิสต์เป็นข้อความรูปแบบอเมริกัน บางเบราว์เซอร์จะสลับวัน-เดือน จึงต้องแยกตัวเลขเองก่อน
